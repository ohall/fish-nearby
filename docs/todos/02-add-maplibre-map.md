# Add MapLibre map

## Technology

**MapLibre GL JS**

## How it works

MapLibre renders the interactive WebGL map; a separate tile/style provider supplies the basemap.

## MVP implementation

- Install `maplibre-gl`.
- Start with point markers.
- Keep tile provider configurable.
- Move to water polygons only after the product works.

## Done when

The item works end-to-end in the deployed MVP and has a focused verification path without leaking source-specific behavior into unrelated layers.
