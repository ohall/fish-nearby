# Tap marker to show species list

## Technology

**Map feature interaction + mobile bottom sheet**

## How it works

Selecting a water body loads details and shows a finger-friendly species list without obscuring the map.

## MVP implementation

- Fetch by water-body ID.
- Highlight selection.
- Use a bottom sheet.
- Preserve map position.

## Done when

The item works end-to-end in the deployed MVP and has a focused verification path without leaking source-specific behavior into unrelated layers.
