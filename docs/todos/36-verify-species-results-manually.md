# Verify species results manually

## Technology

**Golden dataset**

## How it works

A human-reviewed set of expected water/species associations becomes the first meaningful quality benchmark.

## MVP implementation

- Store expected results in JSON/YAML.
- Compare after every normalization change.
- Track false positives/negatives.
- Use errors to improve prompts/rules.

## Done when

The item works end-to-end in the deployed MVP and has a focused verification path without leaking source-specific behavior into unrelated layers.
