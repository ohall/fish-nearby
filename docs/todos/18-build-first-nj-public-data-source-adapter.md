# Build first NJ public-data source adapter

## Technology

**NJDEP ArcGIS REST**

## How it works

NJ Great Fishing Close to Home already provides fishing waters plus primary game fish, making it the best first adapter.

## MVP implementation

- Use point layer first.
- Fetch related Game Fish records.
- Persist NJ source IDs.
- See the data-sources doc.

## Done when

The item works end-to-end in the deployed MVP and has a focused verification path without leaking source-specific behavior into unrelated layers.
