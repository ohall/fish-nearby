# Create Next.js + TypeScript app

## Technology

**Next.js App Router + React + TypeScript**

## How it works

One deployable unit can serve the mobile UI and thin API. TypeScript keeps frontend, API, and ingestion contracts aligned.

## MVP implementation

- Use App Router.
- Keep the map in a client component.
- Keep secrets/server DB access in server modules.
- Avoid splitting frontend/backend until needed.

## Done when

The item works end-to-end in the deployed MVP and has a focused verification path without leaking source-specific behavior into unrelated layers.
